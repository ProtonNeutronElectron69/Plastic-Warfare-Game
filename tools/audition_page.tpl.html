Before you commit

Where these came from

Every music host I would normally use — Musopen, OpenGameArt, Kenney, the Internet Archive — is blocked by this environment's network policy. GitHub is not, so these came from SoundSafari/CC0-1.0-Music, a public mirror that preserves the FreePD library after that site shut down in 2025. All sixteen are from the FreePD portion, originally Kevin MacLeod public-domain dedications.

Treat the licence as good but second-hand. It is a community-aggregated mirror, not the original publisher. Before any of these ship, the track you choose should be confirmed CC0 at its original source — that is a five-minute check per track, and worth doing once rather than never.

These are full tracks, not loops

Every candidate runs one to five minutes. A game loop wants 30–45 seconds that joins back to its own start without a seam, so whichever you pick still needs a loop point chosen and cut. What you are judging here is the material — does this sound like your game — not the edit.

MP3 cannot loop seamlessly

This is the one technical decision that should be made before any files are cut. Every MP3 encoder pads the start and end of a file with a few milliseconds of silence, so a looped MP3 audibly ticks. Your existing 35 sounds are one-shots, where this is invisible.

Two ways out: ship the music as OGG Vorbis instead (no padding, and every browser the game already supports plays it), or keep MP3 and set explicit loop points on the Web Audio source node so the padding is skipped. The first is simpler and is what I would recommend.

What the plumbing already gives you

armsBus in source/js/03-audio.js:65 is the pattern a music bus would copy — its own gain node hanging off masterGain, so music gets a volume of its own without touching the weapons mix. And COMBAT_DUCK_T (line 1003, applied at line 1050) already pulls the mining ambience down during a firefight; pointing it at the music bus too means the score drops back under gunfire for free.

One track worth hearing twice

Night Attack is darker and lower-energy than the other combat candidates. Since v101 the game has a real day/night cycle — so rather than competing with the other four for one slot, it could be the night half of a pair, swapped by dayPhase(). That is a bigger job than four loops, but it is the kind of thing this engine is already shaped for.
